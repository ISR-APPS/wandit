About this guide

This guide explains the complete Wandit V2 report through 16 chapters. Each chapter has four illustrated steps.

The report describes a proposed system. The guide does not establish that these features exist in the product.

Proposal

Simple technical English

The text uses ASD-STE100 writing rules: short sentences, simple verb forms, and one name for each concept.

Full compliance needs a review with the official ASD-STE100 dictionary. This guide does not claim certified compliance.

The illustrations

The workshop, archive, and key are examples. They represent software and computers. Their shapes do not represent physical equipment.

Each scene shows a selected part of the system. The source report contains the technical details.
